03 — Maintenance prédictive
Projet académique — NASA CMAPSS

Maintenance prédictive de moteurs turbofan

Problème

Une panne moteur ne commence pas au moment où la machine s’arrête. Le défi était de repérer la dégradation assez tôt pour estimer quand intervenir.

Ma contribution

Je suis parti des données NASA CMAPSS et j’ai construit la chaîne de bout en bout : simulateur, ingestion Kafka, traitement Spark, stockage InfluxDB, dashboard Grafana et modèle XGBoost.

Impact

Le prototype transforme des flux capteurs en une estimation du RUL visible dans un dashboard. Il montre comment passer d’un modèle isolé à un système exploitable pour préparer une décision de maintenance.

Python · Kafka · Spark Streaming · InfluxDB · Grafana · XGBoost · Docker Voir le dépôt GitHub ↗
